PANDUAN BERMAIN

Kuasai kontrol rubah di Laptop maupun HP

💻 Kontrol Laptop / Keyboard:

  • A / D atau Tombol Panah Kiri/Kanan: Bergerak ke kiri / kanan.
  • W / Tombol Spasi / Panah Atas: Melompat (Tekan 2x untuk Double Jump!).
  • S / Panah Bawah: Menunduk / Turun dari platform tembus.
  • J / Z / F / Tombol X: Tembak Bola Api (Menghabiskan mana, kalahkan monster es!).
  • E: Berinteraksi dengan Altar Checkpoint untuk membuka soal edukasi.
  • P / ESC: Jeda Permainan (Pause).

📱 Kontrol Layar Sentuh HP:

  • ◀ ▶: Bergerak ke kiri dan kanan.
  • ▲ (Tombol Biru): Lompat & Double Jump.
  • 🔥 (Tombol Oranye): Tembak Bola Api Rubah.
  • 📜 (Tombol Ungu): Interaksi dengan Altar Kuno / Checkpoint.
💡 Tips Rahasia: Hancurkan Stone Golem dengan 2 bola api atau injak kepalanya! Ice Elemental terbang secara meliuk, hindari serangannya lalu tembak. Kumpulkan Kristal Ungu untuk mengisi mana bola api!
